# Adapter authoring skill

## Workflow

1. Read `docs/product-specs/adapter-contract.md`.
2. Validate the existing adapter schema.
3. Prefer reusable patterns over domain-specific hacks.
4. Add selectors only for high-value fields.
5. Leave notes explaining why the adapter exists.
6. Add or update at least one fixture or eval.
