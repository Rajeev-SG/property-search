# Site profiling skill

Use this skill when the task is to understand a new estate-agent domain.

## Workflow

1. Read `docs/design-docs/site-profiling.md`.
2. Read the active execution plan related to profiling.
3. Use the source seed file and any site hints.
4. Save findings as durable repo artifacts:
   - site profile JSON
   - notes
   - fixture pages if captured
5. Update docs if you discover a reusable pattern.
