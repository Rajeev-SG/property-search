# Harness Engineering notes

Repository principles to preserve in this repo:

- keep repository knowledge inside the repo
- keep `AGENTS.md` short and map-like
- create and maintain execution plans
- treat tests, CI, docs, evals, and internal tooling as part of the product
- optimize for agent legibility, not only human legibility
- build feedback loops that let agents do reliable work

Use this repo seed to encode those principles before implementation starts.
