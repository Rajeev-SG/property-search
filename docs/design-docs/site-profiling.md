# Site profiling

## Inputs
- domain
- homepage
- start URL
- optional site hints

## Outputs
- sitemap URLs
- robots presence
- candidate listing pages
- candidate detail page patterns
- pagination style
- likely template family hints

## Heuristics
- links containing `/property`, `/properties`, `/for-sale`, `/to-rent`
- repeated card-like structures
- address/price/bedroom token density
- JSON-LD presence
